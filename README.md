# Security Tools

Учебные инструменты информационной безопасности на Python.

## Проекты

### 1. scanp.py — мини-сканер портов (аналог nmap)
- Сканирует порты списком (22,80,443) или диапазоном (1-100)
- Показывает состояние порта и название известного сервиса
- Цветной вывод (colorama)

Запуск:
python3 scanp.py 127.0.0.1 22,80,443

### 2. detector.py — детектор SSH-брутфорса с авто-блокировкой
- Читает лог авторизации и находит неудачные попытки входа
- Считает количество попыток по каждому IP
- Блокирует IP через UFW, если попыток больше 5
- Имеет белый список (whitelist) защищённых IP

Запуск:
sudo python3 detector.py
